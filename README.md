# Subway Prince

An endless subway runner for the browser. Dodge trains, jump hurdles, roll under bars, collect coins, unlock characters and finish the reward goals.

Play: open `index.html`, or use the GitHub Pages link of this repository.

Controls: arrow keys or WASD, swipe on touch screens, P to pause, M for sound.

## Rewards

Finishing both reward goals gives the player a claim code. The game never pays money by itself. The owner checks the code and pays any prize by hand. Goals and the prize text are set in the `REWARD` constant in `index.html`.
